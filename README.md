# Лапа и Дом — Зоомагазин и учёт товаров

Полнофункциональное веб-приложение зоомагазина на **HTML, CSS, чистом JavaScript (ESM + Express) и локальном SQL (SQLite через `sql.js`)** с автономной регистрацией и батником запуска `start.bat` — без внешних и облачных баз данных.

## Структура проекта

```text
├── start.bat                        # Батник для запуска на Windows (двойной клик или CMD)
├── bin/
│   ├── lapa-i-dom                   # Исполняемый CLI-бинарник запуска (--port, --check, --init-db)
│   ├── lapa-i-dom.js                # Кроссплатформенный Node.js-лаунчер
│   └── start.sh                     # Bash-обёртка для запуска на Linux/macOS
├── server.js                        # Express-сервер (порт 3000), API и раздача статики
├── package.json                     # Зависимости (express, sql.js, dotenv) и bin
├── .env.example                     # Опциональные переменные окружения (SQLITE_DB_PATH, PORT)
├── data/
│   └── petshop.sqlite               # Локальная SQL-база данных (создаётся автоматически при старте)
├── sql/
│   ├── schema.sql                   # SQL-схема таблиц (users, suppliers, products, orders, order_items, stock_movements)
│   └── seed.sql                     # Начальное наполнение поставщиков
├── lib/
│   ├── auth.js                      # Хеширование паролей (scrypt) и сессионные токены (HMAC-SHA256)
│   └── db.js                        # Локальный SQLite-движок (sql.js), транзакции и атомарное сохранение
├── middleware/
│   └── auth.js                      # Проверка токенов и ролей (admin / customer)
└── public/
    ├── index.html                   # Страница приложения
    ├── styles.css                   # Стили интерфейса и адаптивная вёрстка
    ├── app.js                       # Клиентская логика на чистом JavaScript (DOM API)
    └── images/                      # Графические ассеты категорий и баннера
```

## Запуск

Внешняя СУБД не требуется — при первом старте автоматически создаётся локальный файл SQL-базы `data/petshop.sqlite` с каталогом, поставщиками и демо-заказами. Первый зарегистрированный пользователь автоматически получает права **администратора**.

1. **На Windows**: запустите **`start.bat`** (двойным кликом или в командной строке, например `start.bat --port 3000`). При первом запуске батник сам установит зависимости.
2. **На Linux / macOS**:
   ```bash
   ./bin/lapa-i-dom --check
   ./bin/lapa-i-dom
   # или через shell-скрипт:
   ./bin/start.sh
   ```
   Также доступен стандартный запуск через npm: `npm run dev` или `npm start`.
